- Lluç / Rape / Morralla (espinas, cabeza y cola)
- Puerro
- Zanahoria
- Apio
- Laurel
- Orégano

Se pone el pescado en olla alta cubierto con agua, al 9.

Se añade la zanahoria, el puerro, el apio y el laurel de golpe.

Puerro: 2 o 3 culos de puerro (zona verde). Se hace un corte en vertical para lavar las capas de tierra bajo el grifo.

Zanahoria: 1 o 2 enteras, peladas, cortadas en 4 trozos cada una.

Apio: 1 rama, cortada en 4 trozos.

Se añade el laurel lavado, unas 2-3 hojas.

Se añade sal, cantidad correspondiente para salar el pescado sobre mesa.

Se añade un chorro de aceite.

Se añaden 3-4 puñados de orégano.

Se deja hervir entre 30-40 minutos, moviendo continuamente para evitar que suba la espuma.

Se retira la espuma más persistente, la oscura, para no estropear el sabor.

Una vez completado el tiempo, se retira del fuego y se deja enfriar.

Una vez enfriado, se cuela el caldo con el colador de tela para atrapar las impurezas.
